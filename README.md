# robotics_turtlebot3  
Burger TurtleBot3 Project for Introduction to Robotics  
View the following [**Quick Start Guide**](https://docs.robotis.com/docs/systems/turtlebot3/quick_start_guide/pc_setup) for assistance on set up  
Using an [**Ubuntu 22.04**](https://releases.ubuntu.com/jammy/) VM with the recommended specs:  
4 cores  
8 GB RAM  
35 GB Disk  
256 MB Video memory  
  
For the [PC Setup](https://docs.robotis.com/docs/systems/turtlebot3/quick_start_guide/pc_setup) page on the quick start guide listed above; Install ROS, TurtleBot package, gazebo, cartographer, and navigation2 using install_pc.sh  

For the [SCB Setup](https://docs.robotis.com/docs/systems/turtlebot3/quick_start_guide/sbc_setup) page, after flashing the OS on your SCB, setting up the network configuration, and enabling ssh: install ROS2 and its relative packages using install_sbc.sh. 

For the [OpenCR Setup](https://docs.robotis.com/docs/systems/turtlebot3/quick_start_guide/opencr_setup) page, after connecting the OpenCR to the SCB using the micro usb cable: install the required packages, specify the OPENCR_MODEL name to be burger, download the firmware and required loader, and upload the firmware to the OpenCR using install_opencr.sh. Check the linked page to determine if the firmware was uploaded successfully.
