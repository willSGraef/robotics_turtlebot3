# robotics_turtlebot3  
TurtleBot3 Project for Introduction to Robotics  
Using an [**Ubuntu 22.04**](https://releases.ubuntu.com/jammy/) VM with the recommended specs:  
4 cores  
8 GB RAM  
35 GB Disk  
256 MB Video memory  
  
Install ROS, TurtleBot package, gazebo, cartographer, and navigation2 using install.sh
